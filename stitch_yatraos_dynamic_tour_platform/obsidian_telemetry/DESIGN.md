## Brand & Style

This design system establishes a high-precision, mission-critical operational cockpit for next-generation luxury travel logistics and multi-modal expedition routing. The visual identity bridges ultra-luxury hospitality with aerospace flight telemetry, evoking unwavering composure, tactical clairvoyance, and bespoke precision.

The style fuses **Glassmorphism** and **Dark-Mode Precision Instrumentation**:
- **Tactical Translucency:** Layered obsidian strata with subtle optical refractions, allowing dense geospatial cartography, kinetic routing nodes, and real-time transit status to exist beneath structured operational surfaces without clutter.
- **Luminescent Telemetry:** Neon-dusted cyan and indigo pathways counterbalanced by high-fidelity semantic state rings (verified emerald, pending amber, critical crimson), establishing instantaneous situational awareness.
- **Cinematic Restraint:** Crisp, engineered borders (0.5px to 1px micro-strokes with radial light-bleed) replace heavy skeuomorphic containment, providing an airy, borderless feel for high-density command centers.

## Colors

The palette draws deeply from deep-space navigation terminals, marine midnight hydrography, and crisp cockpit heads-up displays (HUDs).

### Surface & Canvas Architecture
- **Base Canvas (`#070B14`):** Deep obsidian void. Absolute grounding canvas for extreme contrast and low eye fatigue during overnight dispatch cycles.
- **Surface Elevation 01 (`#0B1120`):** Recessed canvas, structural splitters, and secondary tool docks.
- **Surface Elevation 02 (`#0F172A`):** Standard paneling, module frames, and inactive itinerary card structures.
- **Surface Elevated Overlay (`#1E293B` at 65–85% alpha):** Glassmorphic interactive surfaces featuring background-blur filtration.

### Primary Accents & Signal Nodes
- **Cyan Horizon (`#06B6D4` - Primary):** Route vectors, active waypoints, directional radar pings, and focal telemetry targets.
- **Quantum Indigo (`#6366F1` - Secondary):** Multi-modal linkages, itinerary bridges, AI schedule optimizations, and selected state halos.

### Operational State Matrix
- **Nominal Node (`#10B981`):** Verified clearance, on-schedule transit, booked luxury assets, and confirmed concierge sync.
- **Precautionary Watch (`#F59E0B`):** Environmental variance, connecting gate compression, customs backlog, and predictive weather buffers.
- **Critical Deviation (`#EF4444`):** Stalled transfers, route severance, mechanical grounded status, and urgent passenger re-routing.

### Text & Information Contrast
- **Text Polar (`#F8FAFC`):** Primary data headings, telemetry readouts, mission alerts.
- **Text Slate (`#94A3B8`):** Dynamic labels, secondary metadata, and structural metrics.
- **Text Muted (`#475569`):** Units of measure, grid coordinates, and inactive timestamps.

## Typography

The typographic system bifurcates along qualitative and operational axes:

1. **Human Narrative & Wayfinding (`Plus Jakarta Sans`):** Selected for its geometric structure softened by contemporary humanist nuances. It lends warmth, elite concierge hospitality, and clarity to traveler profiles, luxury itinerary dossiers, and experiential reviews.
2. **Operational Telemetry & Coordinates (`JetBrains Mono`):** Dedicated to technical readouts, chronometers, IATA/ICAO code blocks, GPS positioning, flight corridors, vessel speeds, and currency indices. Tabular figures ensure rock-solid numerical alignment across live-updating charts and manifest grids.
3. **Hierarchy Treatment:** All metadata labels (`label-caps`) enforce uppercase styling with expanded letter spacing to ensure rapid visual triage across dense tactical boards.

## Layout & Spacing

This design system uses a rhythmic 4px/8px modular base with high horizontal density, tailored for telemetry density without visual tension.

### Grid Engine
- **Desktop (≥ 1440px):** 12-column adaptive layout or multi-pane tactical split view (Left: Dynamic Itinerary Tree 360px fixed; Center: Geospatial Neural Canvas fluid; Right: Telemetry & Node Dossier 420px fixed). Gutters: 24px (`space-xl`). Margins: 48px (`space-3xl`).
- **Tablet (768px – 1439px):** 8-column layout. Left itinerary panel collapses into a sliding glass shelf; map and node metrics split 60/40. Gutters: 20px. Margins: 32px (`space-2xl`).
- **Mobile (< 768px):** 4-column fluid stack. Map acts as the viewport canvas with bottom-sheet modal cards snapping to 25%, 50%, and 90% view heights. Gutters: 16px (`space-base`). Margins: 16px (`space-base`).

### Density Principles
- Operational control panels and tabular matrices prioritize compact vertical paddings (4px to 8px) with generous horizontal separation to maintain reading velocity across simultaneous real-time data streams.

## Elevation & Depth

Visual depth is achieved through translucent optical layering, selective back-buffering, and luminescent spectral borders rather than conventional muddy drop shadows.

### Atmospheric Strata
- **Floor Level (Z: 0):** Hex `#070B14` with a subtle radial coordinate grid overlay (`rgba(99, 102, 241, 0.03)`).
- **Sub-surface (Z: 10):** Semi-opaque `#0F172A` at 60% opacity with `backdrop-filter: blur(12px)`. Used for secondary toolbars, docking trays, and map overlays.
- **Flight Deck Panels (Z: 20):** `#0F172A` at 75% opacity, `backdrop-filter: blur(20px)`, framed by a delicate border of `rgba(255, 255, 255, 0.08)`.
- **Active Node Overlays & Drawers (Z: 30):** Elevated glass surfaces (`#1E293B` at 85% opacity, `backdrop-filter: blur(28px)`) enclosed by an inner highlight (`inset 0 1px 0 0 rgba(255, 255, 255, 0.12)`).

### Luminescent Field Edges
Shadows function as atmospheric photon emissions:
- **Default Frame Shadow:** `0 8px 32px -4px rgba(0, 0, 0, 0.6)`.
- **Node Highlight Glow (Cyan):** `0 0 24px -4px rgba(6, 182, 212, 0.25), 0 0 2px 1px rgba(6, 182, 212, 0.4)`.
- **Critical Node Glow (Crimson):** `0 0 24px -2px rgba(239, 68, 68, 0.35), 0 0 4px 1px rgba(239, 68, 68, 0.5)`.
- **Healthy Node Ping (Emerald):** `0 0 16px -2px rgba(16, 185, 129, 0.3)`.

## Shapes

The shape architecture marries fluid aerodynamic ergonomics with the structural rigor of flight displays:

- **Panels & High-Capacity Cards:** Corner radii set uniformly to `16px` (`rounded-lg`), softening the high-tech context and introducing a refined luxury aesthetic.
- **Telemetry Indicators, Status Pills & Sub-controls:** Set to full continuous radii (pill configuration / 9999px) to communicate modular encapsulation and touch/click ergonomics.
- **Data Tables & Instrument Chips:** Set to `8px` (`rounded`) for dense horizontal-vertical scan efficiency without wasted internal padding.
- **Micro-accents:** Cut-corner geometric cues (45-degree chamfers) are reserved exclusively for operational HUD reticles and trip node pulse markers.

## Components

### Buttons & Trigger Systems
- **Primary Telemetry Dispatch:** Gradient-fill (`linear-gradient(135deg, #06B6D4, #6366F1)`), white text (`#FFFFFF`), `font-weight: 600`, 0 0 16px rgba(6, 182, 212, 0.35) glow. On hover, luminance increases 12% with subtle scale pulse.
- **Secondary Ghost Action:** High-translucency slate (`rgba(15, 23, 42, 0.7)`), 1px border (`rgba(255, 255, 255, 0.12)`), text `#F8FAFC`. On hover, border turns `#06B6D4` with text illumination.
- **Critical Abort / Override:** Deep crimson tinted base (`rgba(239, 68, 68, 0.15)`), 1px border (`rgba(239, 68, 68, 0.5)`), text `#EF4444`.

### Node Status Pills & Badges
- Continuous pill form (`border-radius: 9999px`), uppercase `JetBrains Mono` at `10px` (`label-caps`).
- Contains a 6px breathing radar dot:
  - **Nominal Node:** Green dot (`#10B981`) with infinite 2s opacity ring animation; surface `rgba(16, 185, 129, 0.1)`.
  - **Caution Node:** Amber dot (`#F59E0B`); surface `rgba(245, 158, 11, 0.1)`.
  - **Disruption Alert:** Crimson dot (`#EF4444`); surface `rgba(239, 68, 68, 0.15)`.

### Translucent Glassmorphic Cards
- Multi-tier background: `#0F172A` at 80% opacity overlaid with linear gradient (`to bottom right, rgba(255,255,255,0.05), rgba(255,255,255,0.01)`).
- Ultra-fine micro-stroke: 1px border using gradient `linear-gradient(180deg, rgba(255,255,255,0.15) 0%, rgba(255,255,255,0.03) 100%)`.
- Hover behavior: Subtle cyan border bleed (`rgba(6, 182, 212, 0.4)`) and `translateY(-2px)`.

### Operational Input Fields & Selectors
- Background: `#0B1120` inside a 1px border (`rgba(255, 255, 255, 0.08)`).
- Text: `#F8FAFC` (`Plus Jakarta Sans`), placeholder `#475569`.
- Integrated telemetry adornment: Prefix icons or suffix units displayed in `JetBrains Mono` (`#06B6D4`).
- Focused state: Border transitions to `#06B6D4` with ring shadow `0 0 0 2px rgba(6, 182, 212, 0.2)`.

### Mission Control Telemetry Indicators (Custom Components)
- **Node Pulse Connector:** Vertical/horizontal 2px dashed conduit (`#1E293B`) energized with an animated gradient pulse traveling along active transfer segments.
- **Chronos Telemetry Chip:** Monospaced dual-time-zone block displaying UTC Zulu time alongside hyper-local client destination time with visual day/night iconography.
- **Variance Vector Gauge:** Horizontal split-meter displaying real-time delay or advance variance (+/- minutes) color-coded against route thresholds.
