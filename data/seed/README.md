# Demo Dataset

Hand-curated seed data for the demo city (see checklist section 6). One JSON file per city, e.g. `jaipur.json`.

Each place entry:
```json
{
  "name": "",
  "category": "stay | activity | eatery | transport",
  "lat": 0.0,
  "lng": 0.0,
  "avg_cost_inr": 0,
  "avg_duration_min": 0,
  "opening_hours": ""
}
```
